Personal desktop app

Kaamos Ambient uploader

Kaamos Ambient uploader is a desktop application used only by the owner of the Kaamos Ambient YouTube channel. It uploads videos to that channel: long ambient soundscapes and slow music painted from Finnish winter nights.

This is not a public product. It is not offered to other users. This website has no sign-in. It only describes the app and how it handles Google user data.

What the app does

The app runs on the channel owner’s own computer. Its only job is to publish videos the owner chooses:

  • It signs in with the owner’s Google account.
  • It uploads a video file from that computer to the Kaamos Ambient YouTube channel.
  • It can set a custom thumbnail on that upload.
  • It keeps a refresh token on that private computer so later uploads can be published from the same machine.

Why it requests Google data

The app requests only this OAuth scope:

https://www.googleapis.com/auth/youtube.upload

That scope is used to upload videos and set custom thumbnails on the owner’s YouTube channel. The app cannot read Gmail, Google Drive, Google Calendar, or other Google data. It cannot delete videos or change channel settings.

Google user data is not sold and is not shared with third parties. The video the owner chooses to publish is sent to YouTube so it can appear on the owner’s channel. A full account of access, use, storage, and sharing is in the privacy policy.

Who uses it

Only the channel owner, Ville Nores, uses Kaamos Ambient uploader. There is no public signup and no multi-user service.

By using the app, the owner agrees to the YouTube Terms of Service. The app uses YouTube API Services and is also covered by the Google Privacy Policy.
