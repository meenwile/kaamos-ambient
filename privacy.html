Kaamos Ambient uploader

Privacy policy

Last updated 6 November 2026

This policy explains how Kaamos Ambient uploader accesses, uses, stores, and shares Google user data. The app is a desktop program operated by Ville Nores (meenwile@gmail.com) for the Kaamos Ambient YouTube channel. The homepage that describes the app is https://meenwile.github.io/kaamos-ambient/.

The app is for the channel owner’s personal use. It is not a public product and is not offered to other users.

Google user data the app accesses

The app requests only this OAuth scope:

https://www.googleapis.com/auth/youtube.upload

That scope lets the app upload videos and set custom thumbnails on the owner’s YouTube channel. With the owner’s authorization, the app can send a chosen video file, the details needed to publish it (such as a title), and a custom thumbnail to YouTube.

The app does not request, and this scope does not grant, access to Gmail, Google Drive, Google Calendar, or other Google data. The app cannot delete videos or change channel settings. It does not read the owner’s email, files, contacts, or calendar.

How Google user data is used

Google user data is used only so the owner can publish videos to the Kaamos Ambient YouTube channel. Those videos are long ambient soundscapes and slow music painted from Finnish winter nights.

The app uses the granted authorization to:

  • upload a video the owner chooses from the owner’s computer, and
  • set a custom thumbnail on that upload.

Google user data is not used for advertising. It is not sold. It is not used to determine credit-worthiness or for lending. It is not used to train generalized machine-learning or artificial intelligence models. It is not used for any purpose other than uploading videos and setting thumbnails on the owner’s channel.

How Google user data is stored

After the owner authorizes the app, a refresh token is stored locally on the owner’s private computer so the uploader can publish later videos from that computer. The token stays on that computer. It is not uploaded to this website, not stored on a server operated for this app, and not shared with anyone else.

This website is a pair of static pages. It does not ask visitors to sign in. It does not set cookies, does not use analytics or other tracking, and does not collect personal information from people who read these pages.

Video files remain on the owner’s computer except for the copy the owner chooses to send to YouTube for publication. The app does not keep a separate cloud archive of Google account data.

How Google user data is shared

The app does not sell Google user data and does not share it with third parties. No advertiser, data broker, or other outside party receives the owner’s Google user data.

The only transfer is the one required to publish: the video the owner chooses, and the details needed to publish it, are sent to YouTube through Google’s API so the video can appear on the owner’s Kaamos Ambient channel. YouTube then handles that content under Google’s and YouTube’s own terms.

How the data is protected

The refresh token is kept only on the owner’s private computer, which the owner controls. It is not placed on this website, on a shared server, or in a third-party database. Because the app has a single user, the token is not exposed through a public account system.

These pages do not store Google user data at all, so there is no visitor database to protect.

Retention and deletion

The refresh token remains on the owner’s computer until the owner deletes it. There is no server-side copy for this app to retain.

The owner can remove the app’s access at any time on Google’s security settings page: https://security.google.com/settings/security/permissions. After that revocation, the locally stored refresh token no longer works. The owner should then delete the token from the computer. There is no other stored copy of that token to delete.

Videos already published remain on the Kaamos Ambient YouTube channel until the owner deletes them in YouTube. This app cannot delete them.

YouTube API Services

Kaamos Ambient uploader uses YouTube API Services. Use of the app is subject to the YouTube Terms of Service and the Google Privacy Policy.

By using Kaamos Ambient uploader, the owner agrees to be bound by the YouTube Terms of Service.

Changes to this policy

If the app starts to access, use, store, or share Google user data in a new way, this policy will be updated first and the date above will change. The app will not use Google user data for a purpose this policy does not describe.

Contact

Questions or complaints about these privacy practices can be sent to the developer, Ville Nores, at meenwile@gmail.com.
